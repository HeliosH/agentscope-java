- 保留 Domain Port / DAL MyBatis / App 用例的分层，不增加业务 JDBC、第三个数据源或第二套调度事实源。

- 2026-10-10 用户明确取消 R08 结构化企业记忆交付：不新增岗位主数据、个人记忆卡片/候选/冲突及对应管理 UI。保留现有对话、记忆来源和 Mem0 投递能力；R01/R06 中仅为这套新增记忆能力服务的子项也不再作为收尾门禁。
- R11–R17 也保留在全量功能收尾范围中；不能把 P2 不阻塞 P1 发布解释为它们已经完成。
- 未获本轮提交/推送指令，不自动发布版本；保留既有工作区修改和用户文档。
- 本地代码/功能验收与企业实际模型、生产容量、灾备指标实测分别记录。尚无外部验收证据的项目不得标记为生产验收通过。

## 3. 执行顺序

1. **可靠性基础收尾**：R03 流式与容量；R04 分离消费者；R05 Journal/历史门禁；R06 资源引用和工作集冻结。单个功能改动通过针对性测试后再进入联合门禁。
2. **用户任务闭环**：R07 安全重试/对账、R09 确定性产物验证及受控 Verifier。R08 不实施；所有后台工作以已提交 PG/对象版本为输入。
3. **交付与恢复**：R10 应用镜像/配置、真实双应用实例和故障矩阵、浏览器桌面/移动流程、备份/恢复。复用当前企业部署组件，不增加新的消息队列或工作流引擎。
4. **持久扩展功能**：R11 定时任务、R12 授权和凭据治理。触发标准受治理 Run，不创建并行的裸 Harness 调用路径。
5. **运行框架增强**：R13 完整快照与执行计划、R14 远端进程、R15 上下文事实和能力发现、R16 纠偏、R17 完整调用项提前执行。依赖未满足时不提前启用副作用执行。

## 4. 每项完成门禁

- Domain 状态和 Port、MyBatis Adapter、PG/H2 前向迁移及 FORCE RLS、App 用例、实际 runtime 接线、必要 API/UI 均检查，不以 DTO/单测替代使用链路。
- 确定性正向、权限/租户/版本负向、并发 CAS、取消、恢复、禁用/可选依赖降级均有测试。
- 本地真实依赖用例明确启用，记录命令、日志、根退出码及通过/失败/跳过；失败记录保留，修复后完整重跑。
- 浏览器用例注明真实后端或 API fixture，二者不能混记。文件预览同时覆盖桌面/移动布局和实际版本读取。
- 故障演练只操作本轮拥有的应用进程、夹具数据和明确授权的本地依赖；结束时核验任务/租约/保留/GC 队列并恢复初始服务状态，不删除数据卷或无关历史。
